# BEarthStories

BEarthStories documents birth stories, community midwifery practice, and the
lived experience of pregnancy and labor. This repository serves the public site
at bearthstories.com.

- [[birth-centers]] — the freestanding, midwife-staffed alternative to hospital
  and home birth

Clinical and research material lives in the companion `midwifery-wiki`
repository, which is private.
